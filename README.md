# 🔥 Featured Projects

## RFP Bidding Consultation RAG

**Retriever · Multi-Layer Grader · Evaluation**

I built the retrieval and evaluation layer of a hybrid RAG system for public RFP analysis.

Instead of measuring only whether the final answer looks correct, I designed evaluation around the actual failure points of the system:

**Question → Document → Tool → Value → Evidence → Answer**

The system evaluates filtering, extraction, contextual QA, citation alignment, ambiguity, abstention, and regression behavior.

### Key Results

**0.9400 overall evaluation score**
**47 / 50 full-score questions**
**50.96% API cost reduction**
**52.98% runtime reduction**
